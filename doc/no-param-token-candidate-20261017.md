# Platform no-parameter token response: mock contract candidate

This isolated branch now includes the full candidate chain: live host ID/token capture, same-origin client header, existing UUID Worker forwarding gate, backend per-request subject check, and original account-owner derivation. It is **off in the default build and configuration**. No real token, platform request, account lookup, or player save is involved.

The user's earlier relay of Wang Xing's contract says the no-parameter GET returns `data.telegram_id` for the **current Bearer subject**, to compare with live `window.Aigram.id`. This is accepted as the semantic contract for this local candidate; the exact endpoint path was not present in the available handoff. The backend therefore requires an explicit `platformSelfEndpoint` under `https://aigram.aiwaves.tech`, with no query string. The probe requires HTTP 200, JSON `retcode === 0`, JSON `errcode === 0`, and a decimal-string `data.telegram_id` identical to the live ID. It never converts an ID to a JavaScript number. The mock includes `9007199254740993` to catch precision loss.

The default `VITE_HARBOR_PLATFORM_TOKEN_MODE` is unset, so the client retains the published temporary path and drops any caller Authorization. The candidate requires that build switch, Worker `HARBOR_IDENTITY_MODE=platform-verified-v1` and `HARBOR_PLATFORM_TOKEN_MODE=candidate-token-owner-v1`, plus backend identity mode, token mode and the explicit endpoint. None of these were changed on a live service. The Worker uses a fixed non-identity edge placeholder; only the backend derives the old owner hash after a fresh self-subject match. No journey migration is performed.

The tests cover mock success/failure, arbitrary token subject mismatch, error status, retcode, errcode, non-JSON/oversized responses, timeout, Worker gates, and one synthetic SQLite old-journey read. The exact URL, actual response examples, token expiry/revocation behavior, and three real host lifecycles remain for platform/pre-release acceptance. This candidate must not be published or switched on from the mock evidence alone.
