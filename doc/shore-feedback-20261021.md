# 岸边反馈与暂停对练：本地小包

基线正式2c0dfdb。面向原国际海湾生活小镇，保留现有中英本地化。

本包让玩家看见当前可抛竿落点，并能区分无水、太远、遮挡和站位不合法。标记消费原checkShore结果与RPGJS相机投影，不建立指定钓点、第二渲染器或客户端奖励规则。移动后重新检查，确认抛竿时重新取样，服务端仍最后验证。

暂停对练期间可免费领取基础竿/耐用拟饵；不改变练习轮次、成本、报酬或暂停状态。开钓仍与对练互斥，界面明确说明并链接现有地图探索事项，由玩家自行决定是否结束，绝不自动结束练习。服务端在创建挑战前明确拒绝，不依赖最终存档校验报错。

不做完整活动解耦、鱼种持久化、经济/奖励调整、数据迁移、正式发布或玩家操作。合成SQLite/规则及UI静态呈现为本包增量证据，真实UI与手机由原QA在固定新构建复核；不能沿用旧包通过数。
